6 · 诊断解读

✗ advisory violation — OCR_RUN 死契约（G4）

插件 progress parser 声明支持 OCR_RUN 前缀，但后端没有任何命令发射它。这是 #126 吸收 #101 时记录的遗留死契约。诊断：解析器保留了一个永远不会出现的 token，代码维护者可能误以为 run 有进度流。

建议：从 progress-parser.ts 的 KNOWN_PREFIXES 移除 OCR_RUN（或在后端实现），随下一次 UI 迭代处理。

⏳ planned gaps — 延迟交付项

#105 retrieval v2：三意图检索 + 结构感知（schema v7、vec0 论文级 prefilter）—— 排期 post-release，contract 已声明。

#133 确定性收集器：当前审计的证据由人工采集（extractor=manual_audit）；#133 将以 AST/TS-Compiler 收集器替换，并调用同一个 #131 reconciler。

✓ 已实现契约全部满足
